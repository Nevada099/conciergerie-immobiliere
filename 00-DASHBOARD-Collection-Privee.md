# 🔄 LES 3 SERVICES COMBINABLES — le modèle de Collection Privée

> **Le principe (confirmé par Katerina, 15 juil.).** Il y a **3 services de base**, qui fonctionnent comme des **options combinables** :
> **① Transaction** (vente) · **② Location courte/moyenne durée** · **③ Rénovation**.
>
> Le client peut :
> - **Les 3 → cycle complet** (Transaction → Rénovation → Location/Revente) = la **signature** de Collection Privée, le vrai différenciateur.
> - **2 sur 3 → cycle partiel** (on pioche 2 options).
> - **Transaction seule → activité d'agence immobilière classique.**
>
> Les cas cycle complet **et** partiel sont la **preuve vivante** que les piliers se nourrissent. À mettre en avant dans l'offre et sur le site.
